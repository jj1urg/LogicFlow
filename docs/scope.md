# LogicFlow プロジェクトスコープ & 非ゴール（やらないこと）

本ドキュメントは、LogicFlow が **「マインクラフトのレッドストーンのように気軽に組めて、リアルタイムに 4 値信号の動きが直感的に分かるモダンな GUI 論理回路ツール」** というコア価値を守り続けるため、**やること（Scope）** と **やらないこと（Non-Goals）** の境界を明文化します。

機能追加や設計判断に迷った際は、本方針を基準に優先順位および採否を決定します。

---

## 1. やること（Core Scope）

- **直感的な GUI 論理回路エディタ**:
  - ドラッグ＆ドロップ、自動直交配線・手動微調整、配線維持パーツ差し替え、モジュール階層化・シンボル定義など、ストレスの少ない回路作成 UX。
- **リアルタイム 4 値 (`0`, `1`, `X`, `Z`) 論理シミュレーション**:
  - ゼロ遅延・サイクル／イベント駆動による即時フィードバック。バス衝突・発振・Stub 出力・伝搬不定などの X 原因分類と視認性の高い色分け。
- **GUI 主体の視覚的デバッグ体験**:
  - 親回路の信号がリアルタイム反映された状態でのインスタンス内部拡大閲覧（ライブポップアップ）。
  - 複数ワイヤー／信号の現在値を一覧監視する **信号ウォッチ** と、操作・クロックステップ基準の **シンプルな波形タイムチャート**。
- **軽量な HDL 連携（可視化・基本合成・ネットリスト出力）**:
  - 構造記述および基本的な RTL (`assign`, `always_comb`, `always_ff`) の回路図インポート・編集・再合成、未知外部モジュールの Stub 化、Verilog / JSON / DOT エクスポート。
- **クライアント完結・軽快な配布**:
  - ブラウザ完結（静的配信・ローカル保存 `.lcirc.json` / `localStorage`・PWA によるオフライン利用）。

---

## 2. やらないこと（Explicit Non-Goals）

UX の複雑化・エンジンの肥大化・本来の手軽さの喪失を防ぐため、以下は **意図的にスコープ外** とします。

### 2.1 フル機能の HDL テストベンチ実行エンジン（物理時間軸シミュレータ）

- **対象外**: `#10` などの物理時間遅延、`` `timescale `` に基づく時間イベントキュー、`initial` / `forever` / `fork-join` / `wait` などの手続き的テストベンチ実行、`$display` ログ検証、UVM / SystemVerilog Assertions (SVA) の実行・カバレッジ収集。
- **理由**: これらは Verilator・Icarus Verilog・Vivado XSim など専用 HDL シミュレータの領域であり、LogicFlow に持ち込むと UI・コアエンジンともに膨大になります。
- **LogicFlow での代替方針**: テストベンチ実行の代わりに、GUI 上で直感的に使える **信号ウォッチ一覧**・**ステップ基準のシンプルな波形タイムチャート**・**ライブ内部拡大ポップアップ** によって検証・デバッグ体験を完結させます。

### 2.2 物理タイミング解析・アナログ電気特性・FPGA 配置配線 (P&R)

- **対象外**: ゲート伝搬遅延（ns 単位のクリティカルパス・セットアップ／ホールド違反解析）、ハザード／グリッチの過渡解析、SPICE 相当のアナログ電圧／電流計算、FPGA 固有の配置配線やタイミング制約 (`.xdc`) 解釈。
- **理由**: ゼロ遅延の論理動作理解・設計可視化に特化することで、高速なリアルタイム評価とシンプルな操作性を両立します。

### 2.3 商用ツール代替の完全な論理合成コンパイラ & ベンダ IP 再現

- **対象外**: Yosys や Vivado Synthesis の代替となる網羅的な SystemVerilog 言語サポート（複雑な乗除算器合成、高機能 FSM 最適化、任意ユーザー関数の完全インライン展開、クラス／パッケージ等）、および Xilinx `.xci` 等のベンダ独自 IP の内部動作再現。
- **理由**: HDL インポートの目的は「回路構造の素早い可視化と基本動作の確認」です。未定義モジュールや外部 IP は Stub（IO 配線可視化）とし、非 HDL ファイルや未対応構文は **フリーズさせず安全にリジェクト／警告フォールバックする** ことを最優先とします。

### 2.4 重厚なサーバーサイド基盤・常時オンライン前提のアカウント管理

- **対象外**: ユーザー認証・クラウド DB 必須のプロジェクト保存、CRDT 等を用いたリアルタイム多人数共同編集基盤（現フェーズ）。
- **理由**: 静的ホスティング＋ローカル保存（＋PWA）による「開いた瞬間にすぐ触れる」軽快さを維持します。

---

## 3. 例外・見直しルール

本ドキュメントの Non-Goals は、プロジェクトの成長に応じてオーナー（人間）の判断で見直すことができます。ただし、新機能を追加する際は常に **「気軽に組んでリアルタイムに見える」コア UX を損なわないか** を最優先基準として評価してください。
