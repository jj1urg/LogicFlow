# 自作GUI論理回路シミュレーションツール

## Discription

GUIで論理ゲートやモジュールを並べ、直感的に接続でき、リアルタイムに回路の信号の様子(0, 1, x, z)が分かるモダンな操作性、見た目、UI/UXな論理回路シミュレーションソフトを作って欲しいです。

## Background

既存のGUI論理回路シミュレーションツールは、ユーザーエクスペリエンスとして操作性がイマイチだったり、リアルタイムにシミュレーションが出来なかったり、そもそも世の中に少なかったりします。
    デスクトップアプリでは
    - Logisim
    - Digital
    Webアプリでは
    - CircuitVerse
    のようなアプリ
マインクラフトのレッドストーンのような気軽に作成、シミュレーションが出来るツールが欲しくてプロジェクトを立ち上げました。
また、マインクラフト以上に、回路を配置しやすく、そしてモジュール化できるような気軽なツールを作って欲しいです。

## Requirement

- ターゲットはLinuxおよびWeb
    - Webアプリにする場合、基本的にCloudflare Workersにデプロイするかも
- Webベースか、高速に処理できるようにRustベースのどちらかで開発
- Webで動かしたいので、wasm上でRustを動かし、フロントエンドはReact Nativeなどを使って開発するのがよい？(より良い構成があれば、任せます)

## Features

### Essential

- 基本的なマウス、キーボード操作
    - ドラッグアンドドロップでゲートやモジュールの移動
    - 端子の左クリックで簡単にワイヤーの接続
    - 右クリックでネットラベルや各種設定、キーボードで使えるような基本ショートカットの項目
    - コピーアンドペーストや複製などの基本的なショートカット
- マインクラフトのように、wireとゲート端子がリアルタイムに信号の様子が分かるようにする(0, 1, x, z)
    - 0: 灰色
    - 1: 緑色
    - x: 赤色
    - z: 青色
- ワイヤーは重なったりしないように
- グリッドフィットと自由配線を選べるようにする
- ゲート:
    - 基本的な入出力(モジュール入出力、ボタン、レバー、LED、7セグ、マルチビット配線の数値表示器など)
    - 基本論理ゲート
    - 基本組み合わせ回路(MUX, Half-Adder, Full-Adderなど、専用のシンボルがありそうなよく使用される回路)
    - 基本順序回路(各ラッチ、レベルトリガFF、エッジトリガFF)
    - よくある順序回路(RAMなど)
    - ROMなど
- 他のファイルをモジュールとして読み込める機能
- モジュールとして呼び出されるときのシンボルの信号方向や名前などを定義できる機能
- モジュールの見た目を、ただの四角だけでなく、Digitalアプリのように中身の回路を表示してくれる機能
    - 中身の信号までリアルタイムに色を付けるか、付けないかもそれぞれ選択できるようにする
- 大規模になってもしリアルタイム処理が重くなってきたときのために、リアルタイム処理をしないモード(編集モードと実行モードを分けるようなモード)にもできるようにしておく
- 何らかの形式でプロジェクトを保存できるようにする
    - 特に実行環境がWebブラウザの場合

### Optional

- (VHDL/Verilog HDL/)SystemVerilogからインポートし表示する機能
    - 外部モジュールをインスタンス化するようなコードがあり、中身がわからない場合は、中身のない仮のモジュールを配置し、そのファイルにおける配線の様子を視覚化することを優先
- SVのinterfaceのような、配線をまとめ、しかも配線ごとに意味を持たせることができるような機能(?)
- 回路から何らか有用なネットリストをエクスポートする機能
