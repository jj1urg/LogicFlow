## aboud features

* PWA有効化の検討
* 新規モジュールについて、最初からHDLで制作できる機能
* 外部モジュールを参照している回路において、リアルタイムのロジックの動きを拡大して閲覧できる機能
    * 現在の、内部回路を別タブで開く機能(上位モジュールからのシミュレーションの影響は受けない)はそのまま

* 欲を言えば、テストベンチ、シミュレーション構文によって、シミュレーションもできたら嬉しいかもしれないが、機能が多くなりすぎて、UX的にもプログラム的にも膨大になりすぎて溢れてしまっても困るので要相談
    * とりあえず複数のwireをまとめて登録して、まとめて現在の信号を閲覧できる機能を用意するのがよさそうかも
    * シンプルな波形タイムチャートもあったら嬉しいかも
