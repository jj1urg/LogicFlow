## about develop management

### コミットメッセージについて
#### 基本的なフォーマット

```
:絵文字: プレフィックス: abstruct
<空白行>
詳細
```

#### プレフィックス一覧
主に使用したいプレフィックス
* wip: 作業中のとりあえずのコミット
* feat: 新しい何かが増えた ※本番環境(mainブランチ？)ではSemVerにおけるMINORの加算に相当するらしい
* fix: 既存の修正 ※本番環境(mainブランチ？)ではSemVerにおけるPATCHの加算に相当するらしい
* docs: ドキュメントの作成・編集・修正
* refactor: 内部構造の修正
* chore: 雑用の変更
* test: テストの追加・合格
* style: コードフォーマットの微修正
* release: デプロイ・リリース mainブランチへのマージ

#### プレフィックスの絵文字一覧
* 🚧 :construction: (wip) : 作業中のコミット
* ✨ :sparkles: (feat) : 新機能の追加
* 🐛 :bug: (fix) : バグ修正
* 📝 :memo: (docs) : ドキュメントの作成・修正
* ♻️ :recycle: (refactor) : リファクタリング
* 🔧 :wrench: (chore) : 設定ファイルの変更
* ✅ :white_check_mark: (test) : テストの追加・合格
* 🎨 :art: (style) : コードの構造・フォーマットの改善
* 🚀 :rocket: (release) : デプロイ・リリース関連
* 🎉 :tada: (init) : Initial Commit のみ
