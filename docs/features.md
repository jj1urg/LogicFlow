# LogicFlow 機能仕様書

## 1. 基本操作 & UX

- **パーツ配置・差し替え**: 左パレットからキャンバスへドラッグ＆ドロップ、またはクリックで配置。
  - **配線維持のコンポーネント差し替え**: 既存パーツの上へ左パレットから別パーツをドラッグ＆ドロップするか、右クリックメニューの「パーツを差し替え（配線維持）」・インスペクタの「パーツ差し替え」から、位置・回転・互換プロパティ・接続配線を保ったままパーツを差し替え可能（新パーツに対応ピンが無い余剰配線も削除せずフローティング終端として温存）。
  - **配線を残して削除**: 右クリックメニューの「配線を残して削除」により、パーツのみ消去して接続していた配線を延長可能なフローティング終端として残せます。
- **ワイヤー接続・手動調整**: 任意の端子を左クリック → 接続先端子（または既存ワイヤー上の T 字接続点）を左クリックで接続。
  - **グリッド配線モード**: 障害物や既存ワイヤーの重なりを回避して自動直交配線。パーツ移動時も接続ワイヤーを自動再レイアウト。
  - **配線の手動微調整・フローティング配線の再延長**: 自動配線されたワイヤーでも、任意の線分や選択時に表示される角ハンドルをドラッグすることで、ピン接続を保ったまま経路を手動調整可能。既存配線の削除などで終端が未接続（フローティング）になった場合は中抜きリングが表示され、その終端から直接配線を延長・他端子や他フローティング終端へシームレスに統合できます（不要な中点ドットは生成されず、3 方向以上の分岐箇所のみ接続点ドットを表示）。手動調整後に接続先コンポーネントを動かした場合は再び自動再レイアウトされます（右クリックメニュー・インスペクタから単体再レイアウトも可能）。
  - **角丸（フィレット）描画**: ワイヤーの屈折部を滑らかな角丸で描画し、近接・重なり発生時の視認性を向上。
  - **自由配線モード**: 空き領域をクリックして任意の経由点を打ちながら自由角度で配線可能。
- **リアルタイム操作**: スイッチ（トグル）・モジュール入力・クロックはクリックで即座に 0/1 切替、プッシュボタンは押下中のみ 1。
- **トラックパッド / マウス操作切替 & タブ別ビューポート保持**: キャンバス下部の切替スイッチで **自動 / トラックパッド / マウス** の 3 モードを選択可能。各回路タブの拡大縮小・パン状態はセッション内で保持され、別タブから戻っても直前の表示位置を維持します（初回表示および `F` キーで全体フィット）。
  - **トラックパッド**: 二本指スクロールで上下左右のキャンバス移動、ピンチ操作でキャンバス内のみ拡大縮小（キャンバス外はブラウザ標準ズームを維持）。
  - **マウス**: ホイールでカーソル中心ズーム、中ドラッグ / `Space+ドラッグ` / `Shift+ホイール` でキャンバス移動。
  - **自動**: トラックパッドの二本指パン・ピンチズームとマウスのホイールズームを自動判別。
- **右クリックメニュー**: ゲート・ワイヤー・キャンバス背景に応じて、ネットラベル設定、90°回転、コピー/ペースト/複製、モジュール内部表示切替、メモリHEX編集、グリッド整列、全ワイヤー再配線、全体表示などを即実行可能（ショートカット表記付き）。
- **プロジェクト保存 / 読込 & PWA オフライン対応**:
  - ブラウザの `localStorage` へ自動保存（ウォッチリスト含む）。
  - `.lcirc.json` 形式でプロジェクト全体のダウンロード保存・読み込みに対応。
  - **外部モジュール読み込み**: 別の `.lcirc.json` ファイルを現在のプロジェクトへサブモジュールとしてインポートし配置可能。
  - **PWA 対応**: Web App Manifest と軽量 Service Worker により、PC・スマートフォンへのホーム画面インストールおよびオフライン起動に対応。
- **スマートフォン対応 & サイドバー／ポップアップアニメーション**:
  - 左右サイドバー（コンポーネントパレット・インスペクタ）は各パネルヘッダの切替ボタンで滑らかな左右スライドアニメーション付きで収納でき、非表示時はキャンバス左上／右上に「コンポーネントを開く」「インスペクタを開く」フローティングボタンが現れます。
  - 上部の回路タブはドラッグ＆ドロップで順番を入れ替えられるほか、`×` ボタンで最後の 1 枚まで純粋に閉じることができます（モジュール定義は左パレットに保持）。全タブを閉じた 0 タブ状態では中央にスタート画面（新規作成・HDL 読込・既存モジュールのワンクリック復帰）が表示されます。
  - 狭幅画面（`<= 900px`）ではタブ列とアクション列（ウォッチ／HDLソース／シンボル定義）が 2 段に分かれ、左右サイドバーはドロワー形式となります。左カタログからパーツを **ドラッグ＆ドロップ（タッチの右方向ドラッグ／長押しドラッグ含む）** した場合は自動でサイドバーが閉じてキャンバスへ配置でき、**タップ** した場合はサイドバーを開いたまま連続配置できます。キャンバス上では **1 本指ドラッグでパン移動**、**2 本指ピンチで拡大縮小**、**パーツ長押し（約 0.3 秒）→ ドラッグで移動 / 動かさず離して右クリックメニュー表示**（ワイヤー・背景の長押しでもメニュー表示）、**端子タップで配線**、**サブモジュールダブルタップでライブ内部拡大** が可能です。
  - ライブ内部拡大ポップアップは開閉時に拡大縮小アニメーション付きで表示され、トップレベルキャンバスと同様に 1 本指パン・2 本指ピンチズーム・子サブモジュールのダブルタップ潜入、およびヘッダ／右下ハンドルのタッチ移動・リサイズに対応しています。

## 3. シミュレーション実行モード

- **リアルタイムモード**（デフォルト）: 編集・スイッチ操作のたびに即座にシミュレーションを更新。
- **編集 / 実行分離モード**:
  - **編集状態**: シミュレーション処理を完全停止し、大規模回路でも軽快にパーツ配置・配線編集が可能。
  - **実行状態（回路ロック＋事前コンパイル）**: 回路構造の編集をロックしてネットリストグラフを 1 回だけ事前コンパイル（キャッシュ）し、クロック発振やスイッチ/ボタン操作を軽量なランタイム入力オーバーライドのみで高速実行します（プロジェクト JSON のディープコピーや毎ティックのネットリスト再構築を排除）。
- **クロック制御**: 自動発振 Play/Pause、周波数調整 (0.5〜20 Hz)、手動1ステップ反転、順序回路リセット。
- **信号ウォッチ一覧 & シンプルな波形タイムチャート**:
  - 上部タブバーの「ウォッチ / 波形」ボタン、または任意のワイヤー／単一主出力パーツの右クリックメニュー（「ウォッチに追加」）・インスペクタから複数信号を登録し、4 値カラー付きの現在値（`自動 / HEX / BIN / DEC / SIGNED`）を一覧監視可能（「主要I/O一括登録」・上下並び替え・`localStorage` 永続化によるリロード復元にも対応）。登録した信号は右インスペクタ下部のセクション内にも「リアルタイム信号状態」と同じカード形式で常時表示されます。
  - テストベンチ時間遅延エンジンを持たない軽量設計（[`docs/scope.md`](./scope.md) 準拠）として、信号変化時および手動サンプル記録時にステップ単位で最大 128 ステップをリングバッファ記録し、1bit 矩形波・多ビット六角バス波形を Canvas 描画（波形ホバーで過去ステップの値をカーソル参照可能）。

## 4. 搭載コンポーネント一覧

### 入出力 / I/O

- `MODULE_IN` / `MODULE_OUT`: モジュール外部端子（ビット幅・シンボル配置辺の設定可）
- `TOGGLE`（スイッチ/レバー）, `BUTTON`（モーメンタリボタン）, `CLOCK`（発振器）, `CONST`（0/1/X/Z/HEX定数）
- `LED`（4値発光ランプ）, `SEVEN_SEG`（1〜2桁 4/8bit HEXデコード / 7bit直接入力対応）, `NUM_DISPLAY`（HEX/DEC/SIGNED/BIN表示器・多ビット確認向け）
  - ※ ビット幅が異なる配線を直接接続した場合、不足ビットは上位（MSB）を `0` パディング（全ビット `Z` のときは全 `Z`、全ビット `X` のときは全 `X` を維持）、超過ビットは下位ビットのみを使用（切り捨て）して表示します。

### 基本論理ゲート（全種 4 値対応・多ビット対応・2〜8入力可変）

- `AND`, `OR`, `NOT`, `NAND`, `NOR`, `XOR`, `XNOR`, `BUF`, `TRIBUF`（トライステートバッファ）

### 組み合わせ回路

- `MUX` (2〜16 チャネル可変入力・専用台形シンボル), `DEMUX` (2〜16 チャネル可変出力), `DECODER` (2-to-4 / 3-to-8)
- `HALF_ADDER` (HA), `FULL_ADDER` (FA), `ADDER` (Nビット加算器・`Cin` 入力有無切替対応), `COMPARATOR` (Nビット比較器 `<, =, >`)

### 順序回路・メモリ

- `SR_LATCH`, `D_LATCH`（レベルトリガ）
- `D_FF`（`EN` ピン有無切替対応）, `JK_FF`, `T_FF`（立ち上がりエッジトリガ）
- `REGISTER` (Nビット同期レジスタ・`EN` ピン有無切替対応), `COUNTER` (Nビット同期カウンタ)
- `RAM`（アドレス/データ幅可変・インタラクティブ HEX エディタ付き）
- `ROM`（アドレス/データ幅可変・HEX ルックアップテーブル編集対応）

### 配線 / バス / SV 風 Interface

- `TUNNEL`（同名ネットのワイヤレス接続）
- `SPLITTER`（マルチビットバスの分割 / 結合）
- `IFACE_BUNDLE`（SystemVerilog `interface` 風の名前付き構造化バス: 意味のある信号名＋ビット幅を1本のバスに Pack / Unpack）

### モジュール（サブ回路）

- **シンボル定義エディタ**: 任意の回路タブについて、モジュール幅/高さ、各端子の名前・配置辺（左/右/上/下）・並び順をライブプレビュー付きで定義可能。
- **Digital 風 3 段階表示モード**（インスタンス単位および全体一括切替に対応）:
  1. `live`: モジュール内部の回路図を表示し、中のワイヤーやゲートもリアルタイムに 4 値着色
  2. `preview`: モジュール内部の回路図を表示（信号着色なし・軽量）
  3. `box`: シンプルな IC ボックス表示（最軽量）
- **インスタンスのライブ内部拡大ポップアップ（親の信号反映）**:
  - 別タブで開く従来の独立編集・単体テスト機能は維持しつつ、サブモジュールインスタンスの **ダブルクリック** または右クリックメニュー／インスペクタの「ライブ内部を拡大表示（親の信号反映）」で、ドラッグ移動・リサイズ可能なフローティングウィンドウを展開可能（別タブで独立編集したい場合は `Shift + ダブルクリック`・右クリックメニュー・インスペクタ・ポップアップ内「別タブで編集」から開けます）。
  - 親回路の操作をブロックせずリアルタイムに内部信号の動きを拡大・パン閲覧でき、入出力ポートのライブ値チップ表示や、子サブモジュールへのダブルクリック潜入・パンくず移動に対応。

## 5. オプション機能（HDL 連携・ネットリスト出力）

- **Verilog / SystemVerilog インポート & 新規 HDL モジュール作成（HDL プロジェクト管理・複数ファイル一括対応）**:
  - 上部タブバーの **「新規HDL」** ボタンから、最初から Verilog / SystemVerilog コードを書いて新しいモジュールを作成できます（テンプレート自動生成＋ドッキング HDL エディタを編集モードで即オープン）。
  - 1 つまたは複数の `.v` / `.sv` ファイルをまとめて選択・ドラッグ＆ドロップで読み込み、**HDL プロジェクト**（統合ソースグループ）として管理できます。インポート時に **プロジェクト名** と **トップモジュール** を明示指定可能（自動判定も対応）。
  - 左パレットの HDL プロジェクト（**階層モジュールツリー／一覧切替対応**）およびドッキング型 HDL パネルのツリーサイドバーから、トップ配下のインスタンス階層やトップ外モジュールを一覧でき、ワンクリックで「内部回路タブを開く」「HDLソース表示」「トップ指定」「モジュール削除」「プロジェクト一括削除」が可能（外部仮モジュール Stub はパレットには表示されません）。
  - **重なりゼロ自動レイアウト & 迂回コリドー配線**: DFS 循環分離（CPU 等のサブモジュール間フィードバック対応）＋階層トポロジカル配置に加え、間に中間モジュールを跨ぐグローバル `CLK`/`RST` 信号は上部レール（間に障害物がない直接接続は最短配線）、右→左回り込み信号やモジュール跨ぎ長距離配線は下部/上部コリドーへ自動迂回。通常配線もチャネル中央付近で優先的に Y を調整し、モジュールを横切らない見やすい初期配置を行います。
  - `module ... endmodule`（ポートリスト省略形のテストベンチ `module tb; ... endmodule` 含む）、`input`/`output`/`logic`/`wire`、`#(parameter ...)`、`assign`（ビット選択/スライス・連結/複製・複数代入・トライステート複数ドライバ・減算/比較/単項リダクション対応）、論理ゲートプリミティブ、サブモジュールインスタンス化を解析。
  - **手続きブロックの論理合成**: `always_ff` / `always @(posedge ...)`（`if (!rst_n)` 非同期/同期リセット・`if (en)` イネーブル自動抽出・コンパイル時 `for` ループ静的展開・1次元/2次元アンパック配列展開・`$clog2`・インデクス付きパートセレクト `[base -: width]` / `[base +: width]`・符号拡張対応）および `always_comb` / `always @(*)`（`if/else`, `case` 内の条件付き分岐・単一マルチ入力 `MUX` 合成・定数/共通部分式共有・1bit ブール簡約）に対応。
  - **非合成文・未対応ファイルの安全なハンドリング**: Vivado `.xci` (XML)・JSON・バイナリ・`module ... endmodule` を含まない非 HDL ファイルはインポート時に自動でリジェクト／スキップして通知します。また `assert` / `assume` / `cover` / `initial` / `final` / `task` / `function` / `$display` / `$finish` / `` `timescale `` / `typedef` / `import` 等の検証専用文は無視し、未対応の乗除算 (`*`, `/`, `%`) やユーザー関数呼び出しは警告付きで安全にフォールバックします（定数シフト `<<`/`>>`/`<<<`/`>>>`・単項マイナスには対応）。
  - **外部未定義モジュール（仮 Stub）& タブ管理**: 未定義モジュールは IO のみを再現した仮の箱（Stub）として配置（クロック・リセット・AXI-Stream `m_axis_*`/`s_axis_*` 規約と親モジュールのデータフロー解析により入出力方向を自動推論し、Stub 同士のみの配線や複数ドライバ接続も自動配線・4値調停）。多数の `MODULE_OUT` を駆動するモジュールは出力側右列へ自動配置します。インポート時はトップモジュールのみタブに表示し、内部サブモジュールはダブルクリック等でユーザーが明示的に開いた場合のみタブを開きます。
  - **ドッキング型 HDL ソース表示・編集・構文診断・再論理合成**: 画面下部または右側にドッキング表示（リサイズ可）し、HDL ソースを見ながら回路操作・シミュレーションが可能（別の HDL 回路タブへ切り替えると表示ソースも自動追従）。編集モードではリアルタイムのシンタックスハイライト・行番号ガターのエラー／警告表示（クリックで該当行へジャンプ）・VS Code 風ショートカット（`Ctrl+X` 行切り取り / `Alt+↑↓` 行入替 / `Shift+Alt+↑↓` 行複製 / `Ctrl+Shift+K` 行削除 / `Ctrl+/` コメント切替 / `Tab`/`Shift+Tab` 複数行インデント / エディタ内 Undo・Redo）に対応し、構文エラーがある場合は論理合成を安全にブロックします。ソースを編集して「論理合成して反映」すると回路をインプレース再生成でき、回路図側を手動編集した場合は元ソースを維持しつつ「回路側で編集済み（元HDLと分離）」バッジで乖離を通知します。
  - **重なりゼロ自動レイアウト**: 階層トポロジカル列配置＋重心法並び替え＋実サイズに基づくマージン計算により、コンポーネント重なりゼロ・見やすい配線チャネルで初期配置します。
- **ネットリスト エクスポート**:
  - **Verilog HDL (`.v`)**（参照サブモジュールも含めて階層出力）
  - **構造化 JSON Netlist (`.netlist.json`)**
  - **Graphviz DOT (`.dot`)**
