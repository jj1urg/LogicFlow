# LogicFlow

**Verilog / SystemVerilog インポート対応・リアルタイム 4 値論理回路シミュレータ**

LogicFlow は、ブラウザ上で直感的に論理ゲートや階層モジュールを配置・配線し、`0` / `1` / `X` / `Z` の 4 値信号をリアルタイムに可視化しながらシミュレーションできる Web ベースの論理回路シミュレータです。

## 主な特徴

- **リアルタイム 4 値論理シミュレーション (`0`, `1`, `X`, `Z`)**
  - IEEE 1364 準拠の 4 値信号（LOW / HIGH / 不定 / ハイインピーダンス）とマルチビットバス調停に対応。
  - `X` は原因別（**0/1 衝突**・**発振ループ**・**未実装 Stub 出力**・**不定 / 伝播**）に色分け表示され、デバッグが容易です。
  - 組み合わせ発振ループ検出・基本ゲート帰還ループの状態保持（SR ラッチ等）にも対応しています。
- **Verilog / SystemVerilog インポート & ドッキング編集**
  - 単一・複数の `.v` / `.sv` ファイルをまとめてインポートし、HDL プロジェクトとして階層ツリー管理できます。
  - `assign`・`always_ff`・`always_comb`・パラメータ・マルチ入力 `MUX` 合成に対応し、未定義外部モジュールは仮モジュール（Stub）として自動配置します。
  - 画面下部／右側にドッキング可能な HDL ソースパネルからソースを編集し、その場でインプレース再論理合成できます。
  - Verilog (`.v`) / 構造化 JSON Netlist / Graphviz DOT のネットリスト出力にも対応しています。
- **Digital 風 3 段階モジュール表示 & 階層シミュレーション**
  - カスタムサブ回路のシンボル形状・端子配置を自由定義でき、各インスタンスごとに独立した順序回路状態を持ちます。
  - インスタンス表示を `live`（内部回路をリアルタイム信号着色表示）/ `preview`（内部回路プレビュー）/ `box`（軽量 IC ボックス）の 3 段階で切り替え可能です。
- **障害物・重なり回避 A* 自動配線 & 手動経路調整**
  - グリッドフィットモードではゲートや既存配線を回避した直交角丸配線を自動生成し、パーツ移動時も自動再レイアウトします。
  - 線分や角ハンドルをドラッグして手動微調整できるほか、自由配線モードやフローティング終端からの再延長にも対応しています。
- **編集 / 実行分離モード（事前コンパイル高速実行）**
  - デフォルトのリアルタイムモードに加え、大規模回路向けに「編集モード（シミュレーション停止）」と「実行モード（回路ロック＋ネットリスト事前コンパイル）」の分離モードを搭載しています。

## 基本的な操作方法

### キャンバス操作・編集

| 操作 | 方法 |
| --- | --- |
| **パーツ配置** | 左パレットからドラッグ＆ドロップ、またはクリックで配置 |
| **配線** | 端子（またはフローティング配線終端）を左クリック → 接続先端子または既存ワイヤー上（T 字接続）を左クリック |
| **配線の微調整** | ワイヤーの水平/垂直線分または選択時の角ハンドルをドラッグ |
| **リアルタイム入力** | トグルスイッチ・モジュール入力・クロックをクリックで切替、ボタンは押下中のみ `1` |
| **ズーム / パン** | キャンバス下部の切替で **自動 / トラックパッド（2本指パン・ピンチズーム）/ マウス（ホイールズーム・中ドラッグ）** を選択可能 |
| **コンテキストメニュー** | ゲート・ワイヤー・背景を右クリックして回転・ラベル編集・再配線・HEX 編集・内部表示切替などを実行 |
| **HDL インポート / 編集** | 上部ツールバーから `.v` / `.sv` を読み込み、ドッキングパネルで閲覧・編集・再合成（`Ctrl+Enter`） |

### 主なキーボードショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+D` | コピー / ペースト / 複製 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Ctrl+A` / `Delete` (`Backspace`) | 全選択 / 削除 |
| `R` | 選択パーツを 90° 回転 |
| `L` | 選択ワイヤーのネットラベル編集 |
| `G` | グリッド配線 / 自由配線モード切替 |
| `F` | 回路全体を画面にフィット |
| `S` | クロックを 1 ステップ進める |
| `Space + ドラッグ` | キャンバスをパン移動 |
| `Esc` | 配線キャンセル / 選択解除 |
| `?` | ショートカット一覧表示 |

詳細なコンポーネント一覧や仕様は [docs/features.md](./docs/features.md) を参照してください。

## アーキテクチャの特徴

| レイヤー | 採用技術 | 役割・特徴 |
| --- | --- | --- |
| **ツールチェーン** | Vite+ (`vp`) — Vite 8 / Vitest 5 / Oxlint / Oxfmt | ビルド・テスト・型付きリント・フォーマットを単一 CLI に統合 |
| **フロントエンド UI** | React 19 + TypeScript | ダークテーマ IDE 風 UI、タブ管理、ドッキング HDL パネル、インスペクタ |
| **描画エンジン** | HTML5 Canvas 2D (High-DPI 対応) | 60fps 描画、角丸ワイヤー・交差ブリッジ・LOD/カリング・モジュール内部ライブ描画 |
| **シミュレーション基盤** | Pure TypeScript (`src/core/`) | DOM 非依存の純粋ロジック層。将来的な **Rust + WebAssembly (WASM)** カーネル置換を見据えた契約設計 |
| **デプロイ** | Cloudflare Workers Static Assets | `dist/` を静的アセットとしてそのままエッジ配信可能（[wrangler.jsonc](./wrangler.jsonc) 設定済み） |

### ディレクトリ概要

```text
LogicFlow/
├── src/
│   ├── core/        # 4値論理・シミュレータ・A*ルータ・HDL合成/出力・カタログ（DOM非依存）
│   ├── canvas/      # Canvas 2D レンダラ・ヒットテスト
│   ├── store/       # 状態管理・Undo/Redo・実行モード・永続化
│   └── components/  # UI コンポーネント群（Canvas, Palette, TopBar, HdlDockPanel 等）
├── tests/           # Vitest ユニット・結合テスト群
├── docs/            # Open Knowledge Format (OKF) 準拠のドキュメント群
└── wrangler.jsonc   # Cloudflare Workers デプロイ設定
```

詳しい設計は [docs/architecture.md](./docs/architecture.md) を参照してください。

## クイックスタート

### 前提環境

- Node.js
- [Vite+ (`vp`)](https://viteplus.dev/)

### 開発サーバ起動・テスト・ビルド

```bash
# 依存パッケージのインストール
npm install

# 開発サーバ起動 (http://127.0.0.1:5173)
npm run dev

# テスト実行
npm test

# リント・型チェック・フォーマット検証
npm run check

# プロダクションビルド
npm run build
```

### Cloudflare Workers へのデプロイ

```bash
npm run build
npx wrangler deploy
```
